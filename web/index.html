新建环境

不配节点则该环境走本机 IP。多账号务必每个环境配不同出口，否则平台可直接关联。
字母数字下划线短横线，创建后不可改
默认使用本地 Firefox，不依赖任何外部指纹浏览器
已安装版本来自「内核」页
先在「节点池」导入节点，这里才有可选内容

导入配置

导入时已存在的环境、节点、订阅会跳过，不会覆盖。指纹只补缺失的，已有环境的设备身份保持不变（避免平台触发验证）。

Excel 批量导入环境

支持 .xlsx / .xlsm / .csv。必需列「环境编号」，其余列可选。
表头支持中英文（环境编号/编号/id、代理服务器/服务器/ip 等），列顺序随意。
若填写了代理服务器，会自动创建对应节点并绑定。
建议先下载模板，按列填写

Cookie 管理

导出前必须停止该环境（Chrome 会锁住 cookie 库）。
导入的 cookie 以明文写入，Chrome 下次启动会重新加密。
跨机器迁移请用「导出明文 → 目标机导入」的方式。

动态 IP 提取器

填写代理服务商提供的「提取链接」，每次启动环境时自动拉一个新 IP 使用。
链接只能是 http/https，不能指向本机或内网。
支持返回 host:port、user:pass@host:port、JSON 等常见格式

环境设置

用于筛选和标记用途，例如「主力」「备用」「已实名」
随机模式适合「只逛不登录」的号池；已登录店铺账号请用固定，否则平台会因设备突变触发验证
切换后端后需要重新启动环境才生效
可选已安装的 Firefox 版本
